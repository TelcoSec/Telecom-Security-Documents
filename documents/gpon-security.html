Security analysis of GPON networks and attack vectors

Technical Report 2024-01-20 ITU-T Research by RFS

Abstract

This technical report examines security vulnerabilities in GPON (Gigabit Passive Optical Network) technology, analyzing attack vectors, exploitation techniques, and security measures for protecting fiber networks. The study provides practical guidance for securing GPON deployments.
